# Mushroom Meadow template content

Every file in `Source/Genesis.Application.Core/Projects/Templates/Assets/TwoDShowcase/Assets` is generated by
the scripts in this folder. The template's asset folder is ignored by git (`.gitignore`: `**/Templates/Assets/`),
so these scripts are the versioned record of the game. Change a script and re-run it rather than editing the
generated files by hand.

Requirements: Python 3 with Pillow, NumPy and SciPy.

Run from the repository root, in this order (later scripts read images or rooms written by earlier ones):

| Order | Script | Writes |
|---|---|---|
| 1 | `world_art.py` | Meadow Tiles, Morning Sky, Far Hills, Cloud Hills, Meadow Forest, Wayfarer Lodge, Summit Shrine |
| 2 | `worlds_art.py` | Cavern, Grotto, Canopy, Hollow and Village tilesets and backgrounds |
| 3 | `char_art.py` | Pip (Explorer poses), phase-1 creatures and items, HUD icons, Title Logo |
| 4 | `creature_art.py` | NPCs, portraits, enemies, bosses, projectiles, power-ups, props, map marker |
| 5 | `scenes_art.py` | Overworld Map, intro and ending panels, menu and credits backdrops, Lantern Tree Lights |
| 6 | `audio_gen.py` | Phase-1 sound effects, Meadow/Title themes, Meadow Ambience |
| 7 | `music_gen.py` | All other music and ambience (`--verify` re-checks the files) |
| 8 | `sfx_gen.py` | All other sound effects |
| 9 | `fx_gen.py` | Phase-1 particles, shaders, physics, paths, HUD UI, Bounce Mushroom, Spawn Effect |
| 10 | `level_gen.py` | Mushroom Meadow (level 1) room from its ASCII map (`--map` prints it) |
| 11 | `hero_gen.py` | Explorer (Pip), Level Rules, power-ups, Prize markers, Glowspore, Spore Shot, phase-1 actors |
| 12 | `hub_gen.py` | Overworld and Hearthollow rooms, map, villagers, dialogue, shop |
| 13 | `frontend_gen.py` | Intro, Main Menu and Credits rooms, save/load/options scripts |
| 14 | `levels_a_gen.py` | Rootdeep Caverns and Windswept Canopy with Grumblecrag, enemies and the wind |
| 15 | `levels_b_gen.py` | Tidepool Grotto and Duskmantle Hollow with Duskmantle, enemies and currents (`--map`, `--preview`) |

Two files are hand-written: `Assets/Notes/Showcase Guide.md` (the game manual and authoring guide) and
`Assets/Scripts/Time Bonus.pgsl`. Their versioned copies are in this folder: edit them here and copy them into the
template (`Notes` and `Scripts`).

All scripts are deterministic: running the full sequence reproduces the template byte for byte.

Rules the content relies on:
- Resource names are unique across every kind (the Player refuses to start otherwise). An Image that shares
  an Object's name is called `<Name> Sprite`.
- Each resource has a `.meta` with a stable guid derived from its name.
- Validate with `Build.bat --quick --test 2d-showcase` (compiles every PGSL event and plays level 1) and
  `Build.bat --quick --test mushroom-export` (exports and plays level 1 on all five renderers).
