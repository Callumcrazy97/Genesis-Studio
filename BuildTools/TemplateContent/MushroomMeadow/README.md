# Mushroom Meadow template content

Every file in `Source/Genesis.Application.Core/Projects/Templates/Assets/TwoDShowcase/Assets` is generated by
the scripts in this folder. The template's asset folder is ignored by git (`.gitignore`: `**/Templates/Assets/`),
so these scripts are the versioned record of the game. Change a script and re-run it rather than editing the
generated files by hand.

Requirements: Python 3 with Pillow, NumPy and SciPy.

Run from the repository root, in this order (later scripts read images or rooms written by earlier ones):

| Order | Script | Writes |
|---|---|---|
| 1 | `world_art.py` | Meadow Tiles, Morning Sky, Far Hills, Cloud Hills, Meadow Forest, Wayfarer Lodge, Summit Shrine |
| 2 | `worlds_art.py` | Cavern, Grotto, Canopy, Hollow and Village tilesets and backgrounds |
| 3 | `char_art.py` | Pip (Explorer poses), phase-1 creatures and items, HUD icons, Title Logo |
| 4 | `creature_art.py` | NPCs, portraits, enemies, bosses, projectiles, power-ups, props, map marker |
| 5 | `scenes_art.py` | Overworld Map, intro and ending panels, menu and credits backdrops, Lantern Tree Lights |
| 6 | `audio_gen.py` | Phase-1 sound effects, Meadow/Title themes, Meadow Ambience |
| 7 | `music_gen.py` | All other music and ambience (`--verify` re-checks the files) |
| 8 | `sfx_gen.py` | All other sound effects |
| 9 | `fx_gen.py` | Phase-1 particles, shaders, physics, paths, HUD UI, Bounce Mushroom, Spawn Effect |
| 10 | `level_gen.py` | Mushroom Meadow (level 1) room from its ASCII map (`--map` prints it) |
| 11 | `hero_gen.py` | Explorer (Pip), Level Rules, power-ups, Prize markers, Glowspore, Spore Shot, phase-1 actors |
| 12 | `hub_gen.py` | Overworld and Hearthollow rooms, map, villagers, dialogue, shop, Chimney Smoke and its Smoke Puff image (chimney spots read from `worlds_art.py`) |
| 13 | `frontend_gen.py` | Intro, Main Menu and Credits rooms, save/load/options scripts |
| 13a | `options_kit_gen.py` | `Options Kit` library: the Gameplay/Video/Audio options menu with Controls and Remap screens (pause menu and Main Menu); needs `Input Kit` |
| 14 | `levels_a_gen.py` | Rootdeep Caverns and Windswept Canopy with Grumblecrag, enemies and the wind |
| 15 | `levels_b_gen.py` | Tidepool Grotto and Duskmantle Hollow with Duskmantle, enemies and currents (`--map`, `--preview`) |
| 16 | `art_items_gen.py` | Round 4 art: item pickups, held items, arrows, thrown spins, blood stain / gore chunk / slice flash, `Pad Glyphs`, `Key Cap` (`--preview` writes only TestResults contact sheets); `creature_art.py` also adds the `Scared` tag to seven enemy sprites |
| 16b | `items_gen.py` | `Item Kit` library plus `Held Item`, `Item Sword` / `Item Shield` / `Item Bow` / `Item Propeller Flower` pickups, `Thrown Item` and `Arrow` (run after `art_items_gen.py` so the pickups take their own masks; the level generators place the pickups) |
| 16a | `reputation_gen.py` | `Reputation Kit` library (brutality, taint stage, shop multiplier), `Pip Spore Leak` particle and the tainted `Portrait Pip Spore 1-3` images (reads `Portrait Pip`, so it runs after `creature_art.py`; `hub_gen.py` and `frontend_gen.py` use the kit) |
| any | `gore_gen.py` | `Gore Kit` and `Fear Kit` libraries, `Gore Half` / `Gore Chunk` / `Blood Stain` objects and the six-colour `Blood Spray` / `Blood Mist` / `Gore Chunks` / `Blood Drip` / `Slice Spray` particles plus `Pip Spore Cloud` (independent of the other generators; the enemy scripts in `hero_gen.py`, `levels_a_gen.py` and `levels_b_gen.py` call the kits; needs `Reputation Kit` for `RepKill`) |
| any (before the rooms run) | `input_kit_gen.py` | `Scripts/Input Kit.pgsl`: remappable bindings, last-used device, sprint hold/toggle, rebind capture, keycap and controller glyphs (independent of the other generators; reads the `Pad Glyphs` image at run time if it exists) |

Static script check (starts no game): `python check_scripts.py [project folder]` builds `check_scripts_tool/` against the published engine in
`Genesis Application` (needs the .NET SDK) and runs the same strict PGSL validation F5 runs plus a VM compile of every `.pgsl`, printing each
error and warning with its file. Default folder is the template; run it after regenerating. Exit code 0 means no errors.

Playability checks (they write nothing): `hero_physics.py` mirrors Pip's movement constants, hitbox and
frame-by-frame controller (hero_gen.py asserts they match) and offers a reachability search over a generated
room; `reach_meadow.py` proves level 1 completable from its start and checkpoint without power-ups, with no
soft-locks, and replays the acceptance suite's input-only bot route.

Two files are hand-written: `Assets/Notes/Showcase Guide.md` (the game manual and authoring guide) and
`Assets/Scripts/Time Bonus.pgsl`. Their versioned copies are in this folder: edit them here and copy them into the
template (`Notes` and `Scripts`).

All scripts are deterministic: running the full sequence reproduces the template byte for byte.

Rules the content relies on:
- Resource names are unique across every kind (the Player refuses to start otherwise). An Image that shares
  an Object's name is called `<Name> Sprite`.
- Each resource has a `.meta` with a stable guid derived from its name.
- `reach_finale.py` proves Tidepool Grotto and Duskmantle Hollow completable from the start and the
  checkpoint with no power-ups (85% jump margin, no traps); run it after changing `levels_b_gen.py`.
- `reach_hub.py` proves every Hearthollow villager talkable and the way out reachable with no power-ups (full
  and 85% physics, no soft-locks) and that the Overworld marker can walk between every pair of neighbouring
  nodes; run it after changing `hub_gen.py`.
- `reach_levels_a.py` proves Rootdeep Caverns and Windswept Canopy completable from the start and the
  checkpoint with no power-ups (85% margin; moving leaves, the pool, gusts and crumble blocks modelled), no
  soft-locks, climbable thorn trenches and a collectable Glowspore in the closed boss arena; `levels_a_gen.py`
  runs it and fails when it fails (`--no-check` skips it).
- Validate with `Build.bat --quick --test 2d-showcase` (compiles every PGSL event and plays level 1) and
  `Build.bat --quick --test mushroom-export` (exports and plays level 1 on all five renderers).
