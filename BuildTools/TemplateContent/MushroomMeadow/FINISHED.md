# Mushroom Meadow: what "finished product" means, and where it stands

A game is finished when a stranger can install it, play it start to end without help, never meet a bug,
a stall or a dead end, and have a reason to come back. Each line below is measurable. Status is updated
by whoever changes it (S = proven by a run, G = by generator/static check only, ? = not checked, X = known gap).

## A. Flow and content (the whole loop exists)
- A1 Intro -> Main Menu -> Overworld -> levels -> credits -> Main Menu works with keyboard, mouse and controller.
- A2 Five levels, two bosses, village hub, shop, five NPCs, three save slots, options, pause, credits.
- A3 Every level can be completed from its start and every checkpoint without any item (reach_*.py, G).
- A4 Every collectible the game promises (3 Sun Medals a level, 5 Glowspores) can be reached.

## B. Stability (nothing breaks)
- B1 Zero script errors/warnings from check_scripts.py (S) and zero problems in the Player log during a full scripted run of every room.
- B2 mushroom-export passes on all five renderers; 2d-showcase passes.
- B3 Every feature path runs at least once without a script error: items, gore, fear, reputation stages, options pages, remap, save/load/continue, shop, dialogue, credits variants (feature probe). S 28 Oct (qa_probe): every path above ran; 8 bugs fixed, see the status log.
- B4 Saves survive: save, quit, Continue restores progress; an old/corrupt save never crashes. S 28 Oct (Save and Quit, Continue, old / junk / wild / empty saves, junk option slots).
- B5 Resizing/aspect ratios: nothing is cut off at 16:9, 16:10, 21:9 and a small window (screenshots). S 28 Oct for the level HUD, hint bar, pickups, held items and gore at 16:9, 16:10, 2:1, 21:9, 4:3 and 640x360 (pictures); menus / hub / credits at other shapes not looked at.

## C. Performance (smooth and small)
- C1 Frame time uncapped on DX11: p99 <= 8 ms in every level (so 60 fps on weak PCs has 2x headroom); allocation <= 25 KB a frame; no GC pause > 5 ms in play.
- C2 Room load (Play to first frame) <= 3 s for every room; memory flat over a ten-minute loop.
- C3 Exported game folder <= 150 MB; first launch of an export <= 10 s.

## D. Feel and presentation
- D1 Every action has a sound and a visual response (jump, land, hurt, collect, hit, kill, menu moves, shop, save).
- D2 Music and sound levels are even (no sound more than 6 dB louder than its neighbours, music under effects).
- D3 No placeholder text, no developer wording, no overlapping UI, all text readable at 720p (>= 18 px).
- D4 Title screen shows the version; window title and icon are the game's own.

## E. Player support
- E1 Tips, remappable controls, controller glyphs, gore/shake options (done); plus difficulty options (Story / Normal / Challenge).
- E2 A "How to play" page reachable from the pause menu and main menu.
- E3 Progress feedback: completion percentage, medals per level, stats (time played, coins, enemies, reputation) on a Collection/Stats page; achievements with a toast.
- E4 Replay: any cleared level can be re-entered from the map; best medals are kept.

## F. Release
- F1 Export from Studio produces a folder that runs on a machine without Studio; licence file present; version in the project file.
- F2 Documentation: the Showcase Guide matches the game; known issues list empty.
- F3 Source backup taken with Backup.ps1 -KeepLast 3; no test output left behind.
