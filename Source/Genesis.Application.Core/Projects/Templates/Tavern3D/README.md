# Tavern3D optional template

This folder is reserved for an optional example project built entirely from normal Genesis resources.
It is not part of the engine runtime and introduces no special-case gameplay code.

Suitable project-authored examples include busy-room navigation routines, character animation graphs,
conversation scripts, quests, inventories, combat encounters, procedural-layout scripts and stylised
lighting setups. Each example must use the same Room, Object, Model, Pathing, Shader, Audio, UI and PGSL
interfaces available to any end-user project. Engine code must never branch on this template, its asset
names, character roles or its setting.
