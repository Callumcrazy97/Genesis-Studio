Genesis Studio - third-party notices
====================================

Genesis Studio, its Player, and every game exported from Genesis Studio include
software written by other people. This file names each piece, says which
licence it is used under, and reproduces the notices those licences ask to be
kept with every copy.

If you publish a game made with Genesis Studio, keep this "Licenses" folder
with the game. Export puts it there for you.

Files in this folder
--------------------

  SkiaSharp-THIRD-PARTY-NOTICES.txt  notices for Skia and the libraries inside it
  DotNet-LICENSE.txt               the .NET runtime's licence

  Assimp-LICENSE.txt               Genesis Studio only (model import)
The shader compiler's own licences are beside it, in Tools\DXC.
